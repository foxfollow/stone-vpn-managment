Install StoneVPN Manager

From zero to a working menu bar icon in a couple of minutes. Homebrew is the easiest path; a plain .zip works too.

Requirements

  • macOS 26 Tahoe or later, Apple silicon or Intel (universal build).
  • An administrator account — creating tunnels, DNS and route changes need root.
  • The VPN tools you actually use (see VPN backends). Nothing else is bundled.

Option 1 — Homebrew (recommended)

The app lives in the foxfollow/stone tap. Recent Homebrew versions ask you to trust a third-party tap once:

brew tap foxfollow/stone
brew trust --tap foxfollow/stone
brew install --cask stone-vpn-manager

The cask removes the quarantine flag, so the first launch is not blocked. Launch it from Spotlight or with open -a StoneVPNManager.

Option 2 — manual download

  1. Download StoneVPNManager.zip from the latest release.
  2. Unzip it and move StoneVPNManager.app to /Applications — the privileged helper only installs from there.
  3. Allow the first launch. The app is ad-hoc signed (no paid Apple Developer ID), so macOS asks once:
xattr -cr /Applications/StoneVPNManager.app

Or right-click the app → Open → Open. On recent macOS you may also need System Settings → Privacy & Security → Open Anyway.

Each release lists the SHA-256 of the zip. Updates after that are verified by Sparkle with an EdDSA signature before they are installed.

First launch

  1. Menu bar icon. A shield appears in the menu bar (no Dock icon). Grey outline = no tunnels, green with a number = tunnels up, orange = connecting, red “!” = DNS or network problem, purple = a foreign VPN owns the network.
  2. Local Network. macOS asks once whether the app may “find devices on local networks”. Allow it — the DNS and internet probes often talk to a resolver in your LAN; without it the indicators can show false problems.
  3. Privileged helper. Settings → Helper → Install, then approve “StoneVPN Manager” in System Settings → General → Login Items & Extensions. Without the helper everything still works, but every root action asks for your password.
  4. Backends. Settings → Backends: switch off the VPNs you don't use — they are then neither shown nor probed.
The interface is currently in Ukrainian. Menu names on this page are given in English with the meaning; positions are the same.

VPN backends

WireGuard

brew install wireguard-tools

Tunnel configs (.conf) live in the standard wg-quick dirs: /opt/homebrew/etc/wireguard, /usr/local/etc/wireguard or /etc/wireguard. They appear in the popover automatically.

OpenVPN

brew install openvpn

Profiles (.ovpn) are imported in the Profiles window and stored in ~/Library/Application Support/OpenVPN Connect/profiles/ (shared with OpenVPN Connect). The Homebrew binary is used because it writes routes into the kernel correctly. Login and OTP are asked per connect and never stored.

Defguard

Install the Defguard desktop client and add your instance there once. StoneVPN drives it through defguard-client inside Defguard.app; MFA codes are asked in the app.

Cisco Secure Client

Install Cisco Secure Client from your organisation. StoneVPN connects through its vpn CLI — groups are fetched from the head-end, Duo push or passcodes are supported, passwords are not stored. Custom hosts (host:port) can be added in Profiles.

Use it together with the CLI (optional)

The repository also contains the Bash toolkit main-vpn-manager.sh. If the app finds it, both share config.env and state.env:

git clone https://github.com/foxfollow/stone-vpn-managment.git
cd stone-vpn-managment
cp config.env.example config.env      # optional defaults
./main-vpn-manager.sh help

Then point the app at it in Settings → Advanced → Configuration (“shared with the CLI repository”, repository folder). Without the repo the app keeps the same files in ~/Library/Application Support/StoneVPNManager/.

Updates

The app checks for updates daily (Sparkle) — Settings → General → Check for updates…. Because of that, brew upgrade skips it by default; to update through Homebrew anyway:

brew upgrade --cask --greedy stone-vpn-manager

If a new version changes the helper protocol, the Helper tab says “outdated — reinstall”: press Reinstall.

Uninstall

  1. Settings → Helper → Remove (stops and unregisters the root daemon).
  2. Quit the app, then:
brew uninstall --cask --zap stone-vpn-manager

Manual install: delete /Applications/StoneVPNManager.app and ~/Library/Application Support/StoneVPNManager. Your VPN configs are not touched.

Build from source

Needs Xcode 26 or later.

git clone https://github.com/foxfollow/stone-vpn-managment.git
cd stone-vpn-managment
make -C app test       # unit tests of the core package
make -C app install    # Release build → /Applications

Set your own team in Xcode (Signing & Capabilities) or build ad-hoc. Builds from source don't run the auto-updater — update them with git pull and make -C app install.

Troubleshooting

  • “App is damaged and can't be opened” — the quarantine flag: run xattr -cr /Applications/StoneVPNManager.app.
  • Helper shows “requires approval” — open System Settings → General → Login Items & Extensions and switch StoneVPN Manager on.
  • DNS indicator red although the internet works — check that Local Network access is allowed (System Settings → Privacy & Security → Local Network).
  • Ping hangs after a VPN disconnect — popover → DNS → Fix DNS, or ./main-vpn-manager.sh dns fix.
  • Anything else — open an issue.
