Встановлення StoneVPN Manager

Від нуля до робочої іконки в menubar за кілька хвилин. Найпростіше — Homebrew; звичайний .zip теж підходить.

Вимоги

  • macOS 26 Tahoe або новіша, Apple silicon чи Intel (universal-збірка).
  • Обліковий запис адміністратора — створення тунелів, зміни DNS і маршрутів потребують root.
  • VPN-інструменти, якими ти справді користуєшся (див. VPN-бекенди). Нічого іншого в комплекті немає.

Варіант 1 — Homebrew (рекомендовано)

Застосунок лежить у tap foxfollow/stone. Нові версії Homebrew один раз просять довіритися сторонньому tap:

brew tap foxfollow/stone
brew trust --tap foxfollow/stone
brew install --cask stone-vpn-manager

Cask сам знімає прапорець карантину, тож перший запуск не блокується. Запускай зі Spotlight або open -a StoneVPNManager.

Варіант 2 — вручну

  1. Завантаж StoneVPNManager.zip з останнього релізу.
  2. Розпакуй і перенеси StoneVPNManager.app у /Applications — privileged helper встановлюється лише звідти.
  3. Дозволь перший запуск. Застосунок підписаний ad-hoc (без платного Apple Developer ID), тож macOS спитає один раз:
xattr -cr /Applications/StoneVPNManager.app

Або правий клік по застосунку → Open → Open. На нових macOS може знадобитися System Settings → Privacy & Security → Open Anyway.

У кожному релізі вказано SHA-256 архіву. Подальші оновлення Sparkle перевіряє підписом EdDSA перед встановленням.

Перший запуск

  1. Іконка в menubar. З'являється щит (без іконки в Dock). Сірий контур — тунелів немає, зелений з числом — скільки підключено, помаранчевий — підключається, червоний «!» — проблема з DNS чи мережею, фіолетовий — мережу тримає сторонній VPN.
  2. Local Network. macOS один раз спитає, чи можна «шукати пристрої в локальних мережах». Дозволь — перевірки DNS та інтернету часто звертаються до резолвера в LAN; без дозволу індикатори можуть показувати хибні проблеми.
  3. Privileged helper. Settings → Helper → Встановити, далі схвали «StoneVPN Manager» у System Settings → General → Login Items & Extensions. Без helper усе працює, але кожна root-дія питає пароль.
  4. Бекенди. Налаштування → Бекенди: вимкни VPN, якими не користуєшся, — вони не показуються і не опитуються.

VPN-бекенди

WireGuard

brew install wireguard-tools

Конфіги тунелів (.conf) живуть у стандартних теках wg-quick: /opt/homebrew/etc/wireguard, /usr/local/etc/wireguard або /etc/wireguard. У поповері вони з'являються самі.

OpenVPN

brew install openvpn

Профілі (.ovpn) імпортуються у вікні «Профілі» і лежать у ~/Library/Application Support/OpenVPN Connect/profiles/ (спільно з OpenVPN Connect). Використовується Homebrew-бінарник, бо він правильно прописує маршрути в ядро. Пароль і OTP питаються при кожному підключенні й не зберігаються; логін можна запамʼятати для кожного профілю (Налаштування → OpenVPN).

Defguard

Встанови Defguard desktop client і один раз додай там свій інстанс. StoneVPN керує ним через defguard-client усередині Defguard.app; MFA-коди питає сам застосунок.

Cisco Secure Client

Встанови Cisco Secure Client від своєї організації. StoneVPN підключається через його CLI vpn — групи підтягуються з сервера, підтримуються Duo push і passcode, паролі не зберігаються. Власні хости (host:port) додаються у «Профілях».

Разом з CLI (необов'язково)

У репозиторії є й Bash-інструмент main-vpn-manager.sh. Якщо застосунок його знаходить, обидва ділять config.env і state.env:

git clone https://github.com/foxfollow/stone-vpn-managment.git
cd stone-vpn-managment
cp config.env.example config.env      # необов'язкові дефолти
./main-vpn-manager.sh help

Далі вкажи його в Налаштування → Додатково → Конфігурація («Спільно з CLI-репозиторієм», тека репозиторію). Без репо застосунок тримає ті самі файли в ~/Library/Application Support/StoneVPNManager/.

Оновлення

Застосунок щодня перевіряє оновлення (Sparkle) — Налаштування → Загальні → Перевірити оновлення…. Через це brew upgrade за замовчуванням його пропускає; оновити через Homebrew все одно можна так:

brew upgrade --cask --greedy stone-vpn-manager

Якщо нова версія змінює протокол helper, вкладка Helper напише «застаріла — перевстанови»: натисни Перевстановити.

Видалення

  1. Settings → Helper → Видалити (зупиняє й прибирає root-демон).
  2. Закрий застосунок, далі:
brew uninstall --cask --zap stone-vpn-manager

Ручне встановлення: видали /Applications/StoneVPNManager.app і ~/Library/Application Support/StoneVPNManager. Твої VPN-конфіги не чіпаються.

Збірка з вихідного коду

Потрібен Xcode 26 або новіший.

git clone https://github.com/foxfollow/stone-vpn-managment.git
cd stone-vpn-managment
make -C app test       # unit-тести ядра
make -C app install    # Release-збірка → /Applications

Обери свою команду в Xcode (Signing & Capabilities) або збирай ad-hoc. Збірки з коду не запускають автооновлення — оновлюй їх через git pull і make -C app install.

Якщо щось не так

  • «App is damaged and can't be opened» — прапорець карантину: xattr -cr /Applications/StoneVPNManager.app.
  • Helper пише «requires approval» — System Settings → General → Login Items & Extensions, увімкни StoneVPN Manager.
  • DNS-індикатор червоний, хоча інтернет є — перевір дозвіл Local Network (System Settings → Privacy & Security → Local Network).
  • Після відключення VPN «висить» ping — поповер → DNS → Fix DNS або ./main-vpn-manager.sh dns fix.
  • Щось інше — створи issue.
