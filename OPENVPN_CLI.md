# OpenVPN CLI — інструкція

OpenVPN встановлено через Homebrew: `/opt/homebrew/sbin/openvpn`

> Скрипти OpenVPN тепер у теці `scripts/`. Рекомендований вхід — `./main-vpn-manager.sh` (керує і WireGuard, і OpenVPN). Нижче — прямі виклики OpenVPN-скриптів.

---

## Швидкий старт

```bash
# 1. (опц.) дефолти у локальному конфігу:
cp config.env.example config.env      # напр. LAN_GATEWAY=, OVPN_USERNAME=

# 2. (опц.) дефолтний логін, якщо профіль потребує user/pass:
cp auth.txt.example auth.txt && chmod 600 auth.txt   # лише логін в один рядок

# 3. Підключитись / відключитись:
./main-vpn-manager.sh up openvpn
./main-vpn-manager.sh down openvpn
```

---

## Скрипти

### `vpn-up.sh` — підключення

Меню профілів будується **динамічно** зі сканування теки профілів (нічого не
захардкоджено). Логін питається лише якщо профіль має `auth-user-pass`. Шлюз
route-fix — інтерактивний, із запам'ятовуванням останнього вибору.

```bash
./main-vpn-manager.sh up openvpn
```

```
Оберіть VPN-профіль:
  1) my-profile-a                  vpn.example.com:1194
  2) my-profile-b                  10.0.0.1:1194
Номер [1-2]: 2

Логін [Enter=your_username, або введи інший]:
Пароль/OTP для 'your_username': ________
Route-fix шлюз [Enter=192.168.0.1, '-' пропустити, або інший IP]:
Route-fix застосовано через 192.168.0.1
Підключення...
Очікування тунелю......
Підключено!
```

Після підключення маршрути прописуються в ядро. Перевірити:

```bash
route get 10.0.0.1           # має показати interface: utunX
netstat -rn -f inet | grep utun
```

---

### `vpn-down.sh` — відключення

```bash
scripts/vpn-down.sh
```

Зупиняє OpenVPN через PID-файл, якщо PID-файл загублений — знаходить процес по імені. Очищає лог.

---

### `vpn-cert.sh` — керування профілями і сертифікатами

#### Інтерактивне меню

```bash
scripts/vpn-cert.sh
```

```
Керування профілями VPN:
  1) Показати всі профілі
  2) Додати новий профіль (.ovpn)
  3) Замінити сертифікат у профілі
  4) Видалити профіль
```

#### Додати або замінити профіль (шлях як параметр)

```bash
scripts/vpn-cert.sh /path/to/new.ovpn
```

Якщо вже є профіль з таким самим `remote` — запропонує замінити. Якщо новий — додасть з автоматично згенерованим іменем.

#### Видалити профіль

```bash
scripts/vpn-cert.sh --delete
```

Показує список профілів, запитує підтвердження перед видаленням.

#### Замінити окремий сертифікат у профілі

Через меню → пункт `3`:

- **`<cert>`** — клієнтський сертифікат
- **`<key>`** — приватний ключ
- **`<ca>`** — кореневий CA

Вказуєш шлях до `.pem` / `.crt` / `.key` файлу — скрипт вставляє вміст у відповідний блок `.ovpn`. Оригінал зберігається як `.ovpn.bak`.

## Профілі

Зберігаються у:
```
~/Library/Application Support/OpenVPN Connect/profiles/
```

| Файл | Сервер | Порт |
|------|--------|------|
| `<ms-timestamp>.ovpn` | vpn.example.com | 1194 |
| `<ms-timestamp>.ovpn` | 10.0.0.1 | 1194 |

Імена файлів — ms-timestamp (як у OpenVPN Connect). Реальний список профілів:
`./main-vpn-manager.sh cert openvpn` → «Показати всі профілі».

---

## Примітки

- **Логін опціональний.** Питається лише коли профіль має голий `auth-user-pass`.
  Дефолт: `state.env` (останній) → `config.env` (`OVPN_USERNAME`) → `auth.txt`. Можна
  ввести інший або пропустити при підключенні.
- `auth.txt` (якщо використовується) — **лише логін** в один рядок, права `600`.
- `config.env` / `state.env` — локальні (gitignored): дефолти та останні вибори
  (`LAST_GATEWAY`, `LAST_USERNAME`). OTP/пароль **ніколи** не зберігаються.
- `sudo` потрібен — OpenVPN створює tun-інтерфейс що вимагає root.
- Brew-версія OpenVPN (на відміну від GUI OpenVPN Connect) правильно прописує маршрути в ядро.
